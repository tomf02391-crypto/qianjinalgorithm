# ⚡ 千金星轨 · BCLC PC28

基于 **BCLC（加拿大不列颠哥伦比亚省彩票公司）** 官方 Keno 开奖数据的 PC28 分析工具。

## 📐 开奖规则

BCLC 每期开出 **20个数字**（0-79），从小到大排列后：

| PC28数值 | 取位（排序后索引） | 计算 |
|----------|-------------------|------|
| 第一球(a) | 第2,5,8,11,14,17位 | 六数之和取**末位** |
| 第二球(b) | 第3,6,9,12,15,18位 | 六数之和取**末位** |
| 第三球(c) | 第4,7,10,13,16,19位 | 六数之和取**末位** |

**特码 = a + b + c**（范围 0~27）

## 🕐 开奖时间

| 时令 | 北京时间 | 间隔 |
|------|----------|------|
| 夏令时（3月~11月） | 20:00 ~ 次日19:00 | 每3分30秒 |
| 冬令时（11月~3月） | 21:00 ~ 次日20:00 | 每3分30秒 |

## 🔌 数据接口

```
优先级：
1. BCLC 官方 → lotto.bclc.com/keno/results.json
2. 第三方镜像 → yu28.top / pc28.help
3. CORS 代理 → corsproxy.io / allorigins.win
4. 本地种子 → 内置确定性生成（兜底）
```

## 🎯 预测输出

- **主推3个特码** — EMA + 加权频率融合
- **候补2个特码** — 补充覆盖
- **杀5个特码** — 概率最低排除
- **组合押杀** — 大小单双
- **投票详情** — 各信号权重可视化
