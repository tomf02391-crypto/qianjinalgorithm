## 🧠 七信号融合

1. **自适应 EMA** (权重3.0) — 指数移动平均，捕获趋势惯性
2. **双指数平滑** (权重2.0) — 趋势+季节双捕获
3. **加权频率** (权重2.5) — 近期热度衰减加权
4. **一阶马尔可夫** (权重2.0) — 条件转移概率
5. **二阶马尔可夫** (权重1.0) — 状态对转移
6. **差分反转** (权重1.5) — 近期差分方向反转
7. **极值反转** (权重1.0) — 连续极端值回归中枢
